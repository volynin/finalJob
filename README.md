# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

1. Описание проекта

Веб‑приложение для управления задачами с поддержкой периодических событий.

Основные возможности:
* добавление задач с указанием даты, заголовка, комментария;
* настройка правил повторения задач (ежедневно, ежегодно и т. д.);
* просмотр списка ближайших задач;
* отметка задач как выполненных (с автоматическим переносом периодических задач на следующую дату);
* редактирование и удаление задач.

2. Задания повышенной трудности не выполнялись.

3. Шаги запуска
- Клонируйте репозиторий (если ещё не сделано):
git clone <url-репозитория>
cd finalJo
-Установите зависимости: 
go mod tidy
-Соберите проекта (при необходимости):
go build
-Запустите приложение:
go run main.go

4. Адрес в браузере:
http://localhost:7540

5. Тесты 
go test -run ^TestDone$ ./tests
go test -run ^TestDelTask$ ./tests
go test ./tests
Важно: перед запуском тестов убедитесь, что основной сервер (./finalJob) не запущен на том же порту, чтобы избежать конфликтов доступа к БД. 
""Рекомендация"" Следует использовать в случае ошибки: 
fuser -k 7540/tcp
